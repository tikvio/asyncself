# Contributing to AsyncSelf

Bug reports, design discussions, and documentation suggestions are welcome. Before opening a pull
request, read [LICENSING.md](LICENSING.md) so you know which license applies to the target path.

## Apache-2.0 areas

By submitting a contribution to an Apache-2.0-covered path, you agree that your contribution is
licensed under Apache License 2.0 and that you have the right to submit it under those terms.

Keep upstream attribution intact. Changes made directly inside Symphony-derived files remain under
Apache License 2.0 even when they implement an AsyncSelf-specific feature.

## PolyForm Noncommercial areas

The project does not accept code contributions to `local-tools/` or
`.codex/skills/spec-planner/` without a separate written contributor agreement. This is necessary
so the project owner can continue offering commercial licenses for those components.

You may still open an issue describing a bug, requirement, or proposed design. Please do not attach
a patch or paste a substantial implementation unless an agreement has been made first. Contact
**mynewhao@foxmail.com** to discuss a contribution or commercial license.

## Pull requests

- Keep each pull request focused and explain its user-visible effect.
- Add or update tests for behavioral changes.
- Do not include credentials, runtime data, private repository names, or business-project source.
- State whether the changed paths are Apache-2.0 or PolyForm-covered.
- Run the relevant checks described in the pull request template.
